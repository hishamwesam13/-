# كليك كاشير | ClickCashier Pro

منظومة متطورة وذكية لنقاط البيع السحابية (POS)، إدارة المخزون، الحسابات اليومية، وقاعدة بيانات العملاء.

## 🚀 المميزات الرئيسية:
- **هيكل البيانات الهجين (Hybrid Engine)**:
  - **خريطة التجزئة (Hash Map - O(1))**: لإدارة المنتجات، التعديل الفوري للأسعار والكميات في أجزاء من الثانية.
  - **المكدس التفاعلي (Stack - LIFO O(1))**: لعمليات `Push`, `Pop`, `Peek` لتتبع سجل الأسعار والتراجع الفوري (Undo/Redo).
- **كاشير ونقاط بيع ذكية (Smart POS)**:
  - استدعاء الزبائن المسجلين تلقائياً عبر رقم الهاتف أو الاسم.
  - تسجيل الزبائن الجدد وأرقام هواتفهم وحفظهم تلقائياً في قاعدة البيانات.
  - طباعة فواتير ضريبية مبسطة معتمدة.
- **الحماية الصارمة من نفاد المخزون (Out-of-Stock Protection)**:
  - منع بيع أي منتج نافد (0) فوراً وحظر إضافته للفاتورة لحماية الحسابات.
- **جدول الحسابات اليومية ورأس المال والأرباح**:
  - حساب إدخال اليوم الإجمالي، نسبة رأس المال المسترد، وصافي الأرباح المحققة مع شريط بياني نسبي.
- **قاعدة بيانات دائمة (Persistent CRM & Local Database)**:
  - حفظ المنتجات، الفواتير، والعملاء بدون ضياع.
  - إمكانية تصدير واستيراد النسخ الاحتياطية (JSON).
- **دعم كامل للغتين (Arabic RTL & English LTR)**.
